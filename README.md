# REDMAGIC GAME SPACE

Professional Android gaming utility inspired by REDMAGIC 10 Pro Game Space.

**Kotlin + Jetpack Compose | MVVM | Room + DataStore**

> Independent open-source project. Not affiliated with Nubia, REDMAGIC, or ZTE.

## Features

- Performance modes: Eco / Balance / Performance / Beast
- Live CPU, GPU, RAM, temperature, FPS, latency metrics
- ICE Cooling simulation with multi-level fan control
- Charge Bypass and Battery Protection
- RGB lighting modes, colors, brightness
- Per-game profiles
- FPS / latency overlay service
- Digital wellbeing reminders

## Build

```bash
git clone https://github.com/kesrilal518-eng/REDMAGIC-GAME-SPACE.git
cd REDMAGIC-GAME-SPACE
# Open in Android Studio or:
./gradlew assembleDebug
```

Min SDK 26 | Target SDK 35 | JDK 17
